# 🟡 Pacman Game (Python)

A simple Pacman-style game built using Python.
This project demonstrates basic game development concepts like movement, collision detection, and game loops.

---

## 🎮 Features

* Player-controlled Pacman movement
* Basic game mechanics
* Simple and clean Python implementation
* Beginner-friendly project

---

## 🛠️ Technologies Used

* Python
* Standard libraries (no heavy frameworks required)

---

## ▶️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/Vishalmaurya311/Packman-game.git
   ```

2. Go to project folder:

   ```bash
   cd Packman-game
   ```

3. Run the game:

   ```bash
   python packman.py
   ```
